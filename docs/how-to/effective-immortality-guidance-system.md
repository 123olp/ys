# 有效永生：一页行动指南

## 先说结论

现在没人能保证永生。

当前能做的，是：

> 降低提前死亡和失能风险，增加清醒、健康、可行动的时间，同时保留进入未来新技术的能力。

完整闭环只有八步：

```text
目标 → 原理 → 条件 → 决策 → 行动 → 验证 → 纠错 → 迭代
```

## 1. 目标

不要直接追求抽象的“永生”，先保护四件事：

1. 活着；
2. 身体和认知还能正常工作；
3. 有资源、知识和社会支持；
4. 能等待、判断并采用未来技术。

成功不是“证明已经永生”，而是下一阶段比现在：

- 风险更低；
- 有效时间更多；
- 恢复能力更强；
- 未来选择更多。

## 2. 原理

基本逻辑：

```text
活得更久
  -> 获得更多学习、积累和等待时间
  -> 更有能力使用新医学和新技术
  -> 新技术继续提高生存和行动能力
```

但这条链随时可能断裂：疾病、事故、失能、资源不足、错误信息、错误干预和技术不可及，都可能让“活得久”无法变成“有效地继续存在”。

所以不能只盯某个药、某个指标或某项未来技术，必须先处理当前最危险的短板。

## 3. 条件

开始任何行动前，先回答：

1. 现在最大的风险或短板是什么？
2. 有什么可靠证据证明这个行动可能改善它？
3. 最坏可能发生什么？
4. 结果怎样测量？
5. 出问题后能否停止和恢复？

有一项答不出来，就先补信息，不要直接执行。

## 4. 决策

按这个顺序选择：

```text
是否紧急或高风险？
  -> 是：进入合格医疗、应急、法律或专业流程
  -> 否：继续

是否针对当前最大短板？
  -> 否：暂不做
  -> 是：继续

证据是否支持当前用途？
  -> 否：只研究，不执行
  -> 是：继续

是否可停止、可检查、可恢复？
  -> 否：不执行
  -> 是：做最小可验证行动
```

优先级：

1. 防止现实、重大、不可逆的损失；
2. 维护身体、认知和基本生活系统；
3. 提高学习、资源、协作和技术采用能力；
4. 最后才研究高不确定的未来路线。

新奇不等于重要，理论上限高也不等于现在优先。

## 5. 行动

每次只做一个小闭环：

1. 写下一个明确问题；
2. 选出当前最大短板；
3. 比较不超过三个候选行动；
4. 选择风险可控、可测量、可恢复的最小行动；
5. 执行并记录结果。

行动卡只需填写：

```text
问题：
目标：
依据：
具体行动：
负责人：
完成标准：
风险：
停止条件：
检查日期：
```

## 6. 验证

执行前就写清楚：

- 当前基线是什么；
- 多久以后检查；
- 什么结果算有效；
- 什么结果算无效；
- 什么情况必须立即停止。

检查时只问三件事：

1. 真正想改善的能力是否变好了？
2. 是否出现新的伤害、成本或依赖？
3. 结果来自行动本身，还是测量错误、外部变化或自我感觉？

不能判断，就写“无法确定”，不要写“有效”。

## 7. 纠错

| 问题 | 处理 |
| --- | --- |
| 没按计划执行 | 修流程、资源或责任，不评价方法效果 |
| 没有可靠数据 | 改测量方法，结论写“无法确定” |
| 指标变好但人更难受或更难行动 | 停止，说明指标选错或存在副作用 |
| 没效果 | 降级或放弃原假设 |
| 出现伤害或失控 | 立即停止并进入专业处理 |
| 多个行动混在一起 | 拆开重做，避免无法判断原因 |

不要为了证明自己正确而事后更换成功标准。

## 8. 迭代

每轮结束只记录：

```text
做了什么：
结果怎样：
哪里判断错了：
保留什么：
停止什么：
下一步是什么：
```

然后重新寻找当前最大短板，进入下一轮。

## 边界

- 本指南不是医疗、用药、补剂、营养、训练、投资或法律建议。
- 不提供人体、神经、基因、冷冻保存等高风险实验步骤。
- 动物实验、机制推测、短期指标和营销材料不能证明人体延寿。
- 涉及个人健康、高风险或不可逆行动时，必须进入合格专业流程。

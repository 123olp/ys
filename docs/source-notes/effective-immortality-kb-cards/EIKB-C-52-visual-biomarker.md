# EIKB-C-52 | 视觉系统衰老生物标志物

- **标题**: A framework of biomarkers for visual system aging
- **来源**: PMID 40799514 · PMC12342612 · 2024 前后 · 共识
- **证据等级**: B（框架共识）
- **设计**: 视觉系统（视网膜/晶状体/视神经）衰老生物标志物框架
- **核心主张**: 视网膜成像可作为"窗口"观测微血管/神经衰老——眼睛是脑和血管健康的可及窗口
- **关键含义**: 为手册-筛查和监测提供"眼睛=系统窗口"的实证——眼底检查捕捉的不只是眼病
- **不确定性**: 框架仍在研究阶段
- **对应章节**: 手册-监测
- **禁止用途**: 诊断替代

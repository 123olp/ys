# EIKB-C-12 | 记忆印迹稳定性与灵活性

- **标题**: Memory engram stability and flexibility
- **来源**: PMID 39300271 · PMC11525749 · 2024 前后 · 综述
- **证据等级**: C（神经科学综述）
- **设计**: 综述：记忆印迹（engram）的编码、巩固、提取与可塑性
- **核心主张**: 记忆以分布式印迹存储；印迹既稳定又可塑；记忆不是固定文件而是动态重构过程
- **关键含义**: 对"记忆-身份连续性"判据的关键启示：记忆本质上是重构的（提取即重写）——这既支持记忆作为身份锚点，也提示"记忆连续性"的脆弱性（每次回忆都在修改）
- **不确定性**: 小鼠/人类机制差异；印迹与主观记忆体验的对应关系未完全确立
- **迁移边界**: 基础神经科学；不指向记忆备份/上传/编辑技术
- **对应章节**: 指南-哲学判据（记忆连续性）；数字迁移（记忆外化）
- **禁止用途**: 记忆移植/备份可行性声明、记忆编辑操作

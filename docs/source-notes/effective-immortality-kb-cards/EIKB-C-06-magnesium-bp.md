# EIKB-C-06 | 镁补充与血压（系统综述）

- **标题**: Magnesium Supplementation and Blood Pressure: A Systematic Review and Meta-Analysis
- **来源**: PMID 41000008 · PMC12529988 · 2020s · 系统综述+元分析
- **证据等级**: B（RCT 汇总，剂量依赖）
- **设计**: 元分析：镁补充对血压的影响
- **核心主张**: 镁补充可使收缩压/舒张压小幅下降；降幅随剂量增加（约 2-4 mmHg 量级）；对镁摄入不足者更明显
- **关键数字**: 效果量级为 mmHg 级（约 SBP -2~-4）；不是降压药替代
- **不确定性**: 效应量小、异质性、基线镁状态影响；长期安全性数据有限
- **迁移边界**: 有镁缺乏/摄入不足人群；肾功能不全者禁用
- **对应章节**: 手册-补剂实证区（镁）
- **禁止用途**: 高血压治疗替代、个体剂量处方

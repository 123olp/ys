# EIKB-C-61 | 单细胞多组学与精准心血管/长寿医学

- **标题**: Single-cell multi-omics for precision cardiovascular and longevity medicine
- **来源**: PMID 41393100 · PMC12696164 · 2025 前后 · 综述
- **证据等级**: C（技术方法综述）
- **设计**: 单细胞多组学如何应用于心血管/长寿医学的精准化
- **核心主张**: 单细胞分辨率下的多组学（转录/表观/蛋白）可区分"健康衰老"与"病理衰老"的细胞类型特异性轨迹
- **关键含义**: 衰老的未来监测从"全身平均"走向"细胞类型特异"——手册-监测的远期演进方向
- **不确定性**: 临床采集/成本/解读的可行性
- **对应章节**: 指南-维护（多层次监测演进）
- **禁止用途**: 单细胞检测作为常规推荐

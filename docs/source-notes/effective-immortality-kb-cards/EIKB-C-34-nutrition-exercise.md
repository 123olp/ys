# EIKB-C-34 | 营养+运动对老年人肌骨

- **标题**: Nutritional Supplementation Combined with Exercise for Musculoskeletal Health in Older Adults
- **来源**: PMID 42158825 · PMC13181379 · 2025 前后 · RCT/元分析
- **证据等级**: B
- **设计**: 营养补充（蛋白/氨基酸/维D等）+ 运动对老年肌骨
- **核心主张**: 营养+运动联合优于单一干预；蛋白质补充+抗阻训练是肌少症预防的黄金组合
- **关键含义**: 手册的运动与营养两个维度必须联动——单独任何一项都不够
- **不确定性**: 最佳组合方案（蛋白量/时机/类型）仍存异
- **对应章节**: 手册-身体活动 + 手册-营养（交叉引用）
- **禁止用途**: 个体化方案处方

# EIKB-C-38 | 神经形态突触忆阻器

- **标题**: Polymer-Based Linear and Symmetric Artificial Synaptic Memristors
- **来源**: PMID 42274662 · PMC13258654 · 2026 · 器件研究
- **证据等级**: C（硬件器件级研究）
- **设计**: 聚合物人工突触忆阻器（线性/对称特性）
- **核心主张**: 新型聚合物忆阻器实现类生物突触及的线性/对称电导调制——硬件层面向神经形态计算迈进
- **关键含义**: 数字路径的"硬件端"进展——如果连接组是软件端，神经形态器件是硬件端。但今天器件=单突触仿制，与全脑有 >10^10 器件差距
- **不确定性**: 单片→大规模集成鸿沟；与生物神经元的接口问题未解决
- **对应章节**: 指南-数字迁移（硬件子路径进展）
- **禁止用途**: 神经形态=意识可行论证

# EIKB-C-05 | 睡眠时长因果关联（孟德尔随机化）

- **标题**: Causal association between sleep duration, daytime napping, sleep disorders and ...
- **来源**: PMID 41079009 · PMC12510016 · 2025 前后 · 孟德尔随机化
- **证据等级**: B（遗传因果工具变量法）
- **设计**: MR：睡眠时长/午睡/睡眠障碍与结局的因果估计
- **核心主张**: 遗传预测的睡眠时长与多种结局存在因果关联（如代谢/心血管方向）；短睡眠为风险因素
- **关键内容**: MR 提供优于观察性关联的因果证据方向，但依赖遗传工具假设
- **不确定性**: MR 假设（相关性/独立性/排他性）不完全可验证；效应方向与幅度估计区间宽
- **迁移边界**: 欧洲裔样本为主；不能据此给出个体睡眠处方
- **对应章节**: 手册-睡眠（7-9h 依据链之一）
- **禁止用途**: 个体睡眠诊断、用药建议

# EIKB-C-80 | 事件/时间前瞻记忆的神经解剖

- **标题**: The functional neuroanatomy of event-based and time-based prospective memory
- **来源**: PMID 41981065 · PMC13269919 · 2025 前后 · 综述
- **证据等级**: C
- **设计**: 事件触发 vs 时间触发的前瞻记忆的神经基础
- **核心主张**: 事件型（线索触发）与时间型（主动监测）前瞻记忆调用不同脑网络；时间型更依赖前额叶主动控制、更易随年龄衰退
- **关键含义**: 记忆外化工具（日历/提醒）的本质是把"时间型"转为"事件型"——用工具绕过最脆弱的一类记忆
- **不确定性**: 神经影像关联
- **对应章节**: 指南-认知外延（记忆外化机制）
- **禁止用途**: 无

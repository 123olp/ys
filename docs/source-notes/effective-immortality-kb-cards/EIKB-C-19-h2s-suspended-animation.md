# EIKB-C-19 | H2S 悬停动画（药理学）

- **标题**: Is pharmacological, H₂S-induced 'suspended animation' feasible in the ICU?
- **来源**: PMID 25028804 · PMC4060059 · 2014 · 综述
- **证据等级**: C（药理学概念+动物实验）
- **设计**: 综述：硫化氢（H₂S）诱导低代谢"悬停动画"状态的可行性
- **核心主张**: H₂S 等气体信使分子可在动物模型诱导可逆的低代谢（降低氧气消耗/体温）；为 ICU/创伤中"买时间"的暂停策略提供药理学概念验证
- **关键含义**: 这是生物暂停路径中最接近临床验证药物的一条（H₂S/还原态诱导），但距真实人体"暂停-恢复"无损伤仍远
- **不确定性**: 动物→人体外推；常温条件下效果弱于低温合用
- **对应章节**: 指南-生物暂停（冬眠/悬停动画路径）
- **禁止用途**: 任何 H₂S 吸入/注射的人体建议

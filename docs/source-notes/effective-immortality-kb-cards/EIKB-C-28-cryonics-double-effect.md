# EIKB-C-28 | 冷冻保存与安乐死的双重效应

- **标题**: Cryonics, euthanasia, and the doctrine of double effect
- **来源**: PMID 37381023 · PMC10308608 · 2023 · 伦理学分析
- **证据等级**: I（伦理/法律分析）
- **设计**: 用双重效应原则分析冷冻保存与安乐死/协助死亡的伦理边界
- **核心主张**: 冷冻保存前的死亡协助（如为优化保存时机而在死亡前辅助终止）存在深刻的伦理/法律问题——它是暂停路径无法回避的"进入门"困境
- **关键含义**: 暂停路径有一个硬道德问题：为了一个未兑现的未来技术，现在如何"合法地死"——这不是技术问题而是文明选择题
- **对应章节**: 史-思想运动（冷冻伦理史的一部分）；指南-暂停（阻塞点补充）
- **禁止用途**: 冷冻/安乐死建议

# EIKB-C-68 | 脑死亡态度与医学教育

- **标题**: Changes in Medical Students' Knowledge and Attitudes Toward Brain Death
- **来源**: PMID 39410946 · PMC11473080 · 2024 前后 · 调查研究
- **证据等级**: C（调查）
- **设计**: 医学生对脑死亡认知和态度的变化
- **核心主张**: 即使医学生也对脑死亡的概念存在理解偏差和态度不确定性
- **关键含义**: "死亡定义"是文化构建+医学事实的混合——永生/主体连续性的"什么算死亡"需要同时考虑法律/医学/哲学
- **不确定性**: 调查样本有限
- **对应章节**: 指南-哲学判据（死亡定义=连续性判据的前提）
- **禁止用途**: 死亡判定标准建议

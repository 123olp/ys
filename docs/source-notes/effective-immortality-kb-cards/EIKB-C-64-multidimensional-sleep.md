# EIKB-C-64 | 睡眠多维度系统综述方案

- **标题**: Beyond sleep duration: protocol for a systematic review of multidimensional sleep
- **来源**: PMID 41424529 · PMC12713809 · 2025 前后 · 方案
- **证据等级**: B（方案级，方向性指导）
- **设计**: 超越"时长"的多维睡眠健康系统综述协议
- **核心主张**: 睡眠健康的评估应超越"几小时"——包括规律性、连续性、深度、主观质量
- **关键含义**: 手册-睡眠章需要从"7-9小时"升级为多维——规律性（定时）、连续性（不中断）可能同等于时长
- **不确定性**: 方案尚未完成；多维指标的人群证据还需积累
- **对应章节**: 手册-睡眠（未来进化方向）
- **禁止用途**: 当前临床诊断标准

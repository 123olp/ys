# EIKB-C-49 | 干细胞治疗帕金森病

- **标题**: Stem Cell Therapy for Parkinson's Disease: A Mechanistically Distinct Role for MSC
- **来源**: PMID 42279231 · PMC13257467 · 2026 · 综述

- **对应章节**: 指南-生物重建（干细胞治疗现状）

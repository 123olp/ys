# EIKB-C-17 | 表观时钟漂移机制

- **标题**: Epigenetic drift underlies epigenetic clock signals, but displays distinct response to...
- **来源**: PMID 38285616 · PMC10866415 · 2024 前后 · 机制研究
- **证据等级**: C（机制解释研究）
- **设计**: 分析表观时钟的"漂移"（epigenetic drift）如何驱动时钟信号
- **核心主张**: 表观时钟信号部分由正常老化中的随机甲基化漂移贡献；漂移不同于程序性变化
- **关键含义**: 表观时钟不一定是"老化程序"的读出——可能部分是噪声积累。这对"逆转时钟=逆转衰老"的热门叙事是重要的冷却剂
- **不确定性**: 漂移的因果角色未定
- **对应章节**: 指南-维护（表观时钟的证据边界）；手册-监测
- **禁止用途**: 表观时钟逆转 = 抗衰生效的声明

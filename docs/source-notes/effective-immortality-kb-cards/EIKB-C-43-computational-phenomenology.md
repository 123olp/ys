# EIKB-C-43 | 计算现象学时间意识

- **标题**: Time-consciousness in computational phenomenology: a temporal analysis of active inference
- **来源**: PMID 36937108 · PMC10022603 · 2023 · 理论/计算研究
- **证据等级**: D（计算模型/理论推导）
- **设计**: 用主动推理（active inference）框架建模时间意识的计算现象学
- **核心主张**: 时间意识可能具有可计算建模的结构——不是不可言说的"谜"而是可形式化的过程
- **关键含义**: 对第一原理（体验连续性）的关键输入：如果"体验"的时间结构可被建模，"体验是否可被复制"从此不再是纯哲学问题
- **不确定性**: 计算模型=模拟≠体验；现象学与计算的鸿沟仍在
- **对应章节**: 指南-数字迁移（意识可计算建模的进展）；哲学判据
- **禁止用途**: 意识建模=意识可复制

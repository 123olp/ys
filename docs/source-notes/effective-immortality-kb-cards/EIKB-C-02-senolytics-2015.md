# EIKB-C-02 | Senolytics 综述（Achilles' heel）

- **标题**: The Achilles' heel of senescent cells: from transcriptome to senolytic drugs
- **来源**: PMID 25754370 · PMC4531078 · Aging Cell 2015 · 综述
- **证据等级**: C（机制+动物；人体证据后续才起步）
- **设计**: 叙述性综述：衰老细胞转录组特征 → senolytic 药物策略
- **核心主张**: 衰老细胞通过 SASP 驱动组织衰老与慢病；基于转录组可识别其"阿喀琉斯之踵"（抗凋亡通路依赖），设计选择性清除药物（senolytics）
- **关键内容**: 综述了 senolytic 候选（达沙替尼+槲皮素等）在动物模型延长健康期的证据
- **不确定性**: 人体安全性与长期效果未定；清除衰老细胞是否净获益（组织修复角色）未解决
- **迁移边界**: 动物→人体外推受限；候选药物均为离标签/研究用途
- **对应章节**: 指南-生物维护（Senolytics 路径，证据 C/10-30 年）；手册-补剂候选区
- **禁止用途**: 任何 senolytic 药物自行使用建议、治疗承诺

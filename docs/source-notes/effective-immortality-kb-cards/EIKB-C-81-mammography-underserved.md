# EIKB-C-81 | 乳腺筛查弱势群体系统综述

- **标题**: Advancing Mammographic Screening Among Underserved Groups: A Systematic Review
- **来源**: PMID 40256640 · PMC12006734 · 2024 前后 · 系统综述
- **证据等级**: B
- **设计**: 乳腺筛查在弱势群体（低收入/少数族裔/农村）中的差异与改善策略
- **核心主张**: 筛查差距主要来自可及性/导航/费用而非生物学——导航服务（navigator）可缩小差距
- **关键含义**: 筛查效果=技术×可及性——个人层面的"按时筛查"需要在系统层面才真正可行
- **不确定性**: 改善策略效果因环境而异
- **对应章节**: 手册-代谢筛查（可及性维度）；指南-社会复合
- **禁止用途**: 无

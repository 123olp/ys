# EIKB-C-09 | LLM 无法拥有意识（IIT 论证）

- **标题**: Why large language models cannot possess consciousness: an integrated information...
- **来源**: PMID 41331515 · PMC12800557 · 2025 前后 · 理论论证
- **证据等级**: D（理论/概念论证，非实证）
- **设计**: 用整合信息理论（IIT）框架论证 LLM 不具备意识
- **核心主张**: 基于 IIT（Φ/整合信息标准），LLM 的架构缺乏真正的因果整合结构，故不满足意识必要条件；"图灵测试通过"不等于"有意识"
- **关键含义**: 为"数字迁移/意识上传"路径提供概念性否定——仿真意识≠意识；这支撑指南-数字路径的标尺检验（体验不可验证）
- **不确定性**: IIT 本身是有争议的意识理论；结论依赖理论前提
- **迁移边界**: 概念论证，不直接可证伪；不能作为"AI 必然无意识"的定论
- **对应章节**: 指南-数字迁移（意识上传路径的阻塞点）；哲学判据
- **禁止用途**: 作为 AI 伦理立法的唯一依据、意识有无的绝对判定

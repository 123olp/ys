# EIKB-C-47 | ROS 与星形胶质缺陷

- **标题**: Endogenous ROS cause astrocyte defects and neuronal dysfunction in a model of aging
- **来源**: PMID 27623715 · PMC5242301 · 2016 · 动物机制研究
- **证据等级**: C（动物模型机制）
- **设计**: 小鼠模型：内源性 ROS 导致星形胶质细胞缺陷→神经元功能障碍
- **核心主张**: ROS 损伤星形胶质细胞（而非直接杀神经元）是年龄相关神经退行的关键中间环节
- **关键含义**: 抗氧化策略不应只针对神经元——支持星形胶质/神经血管单元可能是更有效的"神经保护"靶点
- **不确定性**: 小鼠→人
- **对应章节**: 指南-维护（氧化应激路径的谨慎评估）
- **禁止用途**: 抗氧化补充剂延寿/护脑

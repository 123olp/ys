# EIKB-C-20 | 认知增强神经技术综述

- **标题**: Neurotechnologies for Human Cognitive Augmentation: Current State and Future Prospects
- **来源**: PMID 30766483 · PMC6365771 · Frontiers 2019 · 综述
- **证据等级**: C（技术综述）
- **设计**: 综述：神经技术（tDCS/TMS/BCI/神经反馈等）用于人类认知增强的现状
- **核心主张**: 现有技术具有任务内微调效果（注意力/工作记忆），但效果小、个体差异大、长期转移证据不足
- **关键含义**: "认知增强"当前不是技术通道，而是外部工具+训练通道（知识管理/AI 协作/认知训练）——这支撑指南将认知外延置于"工具层"而非"神经干预层"
- **不确定性**: 效果异质性高；技术成熟度与安全性各异
- **对应章节**: 指南-认知外延（神经干预子路径的现状）
- **禁止用途**: 神经增强技术可及/有效的声明

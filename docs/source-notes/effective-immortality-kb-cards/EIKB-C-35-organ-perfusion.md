# EIKB-C-35 | 离体器官灌注用于疾病建模

- **标题**: Ex Vivo Organ Perfusion Systems for Disease Modeling and Therapeutic Application
- **来源**: PMID 41018117 · PMC12463510 · 2024 前后 · 综述
- **证据等级**: C（平台技术综述）
- **设计**: 离体灌注系统在疾病建模/治疗中的应用综述
- **核心主张**: 离体灌注能维持器官活力数小时-数天，用于药物测试/疾病建模/移植前"修复"
- **关键含义**: 这是"器官修复"路径的中间技术——不是替换而是修复现有器官（为重建族补充修复支线）
- **不确定性**: 长期体内移植前与灌注修复的效果未知
- **对应章节**: 指南-生物重建（修复子路径）
- **禁止用途**: 临床可用声明

# EIKB-C-07 | 连续 vs 间歇热量限制（RCT）

- **标题**: The Effects of Continuous vs. Intermittent Caloric Restriction on Fat Loss
- **来源**: PMID 42280466 · PMC13258728 · 2020s · 随机对照试验
- **证据等级**: B（RCT，单中心量级）
- **设计**: 连续 CR vs 间歇 CR（如 5:2）随机对照
- **核心主张**: 两种模式在减脂/代谢指标改善上总体相当；依从性决定效果；无证据显示间歇模式有额外长寿优势
- **不确定性**: 减重≠延寿；长期（数年）效应与依从性维持未定；动物 CR 延寿证据不等于人体等效
- **迁移边界**: 超重/一般成人能量管理；不适用于营养不良、妊娠、进食障碍史者
- **对应章节**: 手册-营养（能量平衡）；指南-维护（CR 路径，人体证据 B）
- **禁止用途**: 极端节食处方、禁食作为治疗

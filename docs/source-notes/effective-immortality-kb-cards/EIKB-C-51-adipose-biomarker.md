# EIKB-C-51 | 脂肪组织衰老生物标志物框架

- **标题**: A framework of biomarkers for adipose tissue aging
- **来源**: PMID 41089668 · PMC12517170 · 2025 前后 · 共识声明
- **证据等级**: B（专家共识框架）
- **设计**: 脂肪组织衰老生物标志物共识框架
- **核心主张**: 脂肪组织功能质量（不是重量/BMI）是衰老的核心生物标志物
- **关键含义**: BMI/体重是粗糙代理，脂肪组织"健康度"才是关键——支撑手册-代谢章将"代谢风险"从"减重"升级为"脂肪质量"
- **不确定性**: 生物标志物进入临床仍有距离
- **对应章节**: 手册-代谢筛查；指南-维护
- **禁止用途**: 临床诊断替代

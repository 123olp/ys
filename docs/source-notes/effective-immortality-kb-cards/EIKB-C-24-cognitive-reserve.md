# EIKB-C-24 | 认知储备对抗血管性痴呆

- **标题**: Cognitive reserve against vascular contributions to cognitive impairment
- **来源**: PMID 42309982 · PMC13275331 · 2026 · 综述
- **证据等级**: C（概念+纵向证据综合）
- **设计**: 综述认知储备（cognitive reserve）在抵抗血管性脑损害中的作用
- **核心主张**: 终生认知刺激（教育/职业/休闲）建立"认知储备"，缓冲脑病理负担的影响——延缓痴呆临床表现
- **关键含义**: "终身学习/用脑"不是老生常谈——它有神经证据支撑。认知储备路径是"认知外延"的生物学锚点
- **不确定性**: 关联性（高储备者可能整体更健康）；因果干预策略未建立
- **对应章节**: 指南-认知外延（终身学习的证据）；手册-环境
- **禁止用途**: 认知训练产品营销承诺

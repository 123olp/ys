# EIKB-C-78 | 表观时钟预测生育力时间线

- **标题**: Epigenetic age and fertility timeline: testing an epigenetic clock to forecast infertility
- **来源**: PMID 40660261 · PMC12257822 · 2024 前后 · 队列验证
- **证据等级**: C（早期验证）
- **设计**: 表观遗传年龄预测生育力时间线的测试
- **核心主张**: 表观年龄可能比日历年龄更好反映生殖衰老的个体差异
- **关键含义**: 表观时钟的应用场景扩展（生育力/未来选择权）——生物年龄工具对"未来选择权"路径有现实意义
- **不确定性**: 早期验证、样本有限
- **对应章节**: 指南-维护（生物年龄的应用边界）；指南-社会复合（未来选择权）
- **禁止用途**: 个体生育诊断

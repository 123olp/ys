# 公共作品集：有效永生三件套

本目录是 Human Infra 的公共作品集（内部使用版），由三个相互衔接的作品构成一条完整认知链路：

```text
过去 ←────── 永生史（人类已经走过的全部路）
现在 ←────── 健康手册（此刻就能执行、实证支撑的方法）
未来 ←────── 永生指南（所有可能的路径：现在可走 + 未来可能）
```

## 作品清单

| 作品 | 时间维度 | 文件 | 对象 |
| --- | --- | --- | --- |
| 永生史 | 过去 | `history-of-immortality.md` | 人类追求永生的全部历史事件：神话宗教、古代实践、近代转折、现代技术、思想运动、文学影响、失败教训 |
| 健康手册 | 现在 | `health-handbook.md` | 实证支撑的可执行健康维持方法：营养膳食、补剂、身体活动、睡眠、代谢筛查、环境社会 |
| 永生指南 | 未来 | `effective-immortality-guide.md` | 所有可能的路径：生物维护、生物重建、生物暂停、数字迁移、认知外延、社会复合、哲学判据 |

## 核心原则

- 目的：**有效永生**；三件套是认知手段，其他实现是执行手段
- 用途：内部使用，个人决策辅助
- 唯一约束：物理规律；内容基于真实机制与可验证事实，标注确定性与风险
- 第一原理锚点：主体的"体验-记忆-选择"三重连续性必须被无限保持

## 相互关系

```text
永生史 → 告诉路径从哪来（史实/教训）
永生指南 → 告诉路径往哪去（全景/阻塞点/时间窗口）
健康手册 → 告诉当下走哪条、怎么走（重叠区 = 指南中"现在可走"的路径族）
```

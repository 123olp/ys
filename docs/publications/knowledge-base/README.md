# 有效永生知识库

本目录是"有效永生"主题的资料知识库：**全部相关资料的分类索引与元数据层**。

## 定位（P2 Literature Mapping）

- 科研阶段：P1 Scoping → P2 Literature Mapping（范围综述前期）
- 职责：把与有效永生相关的全部资料（哲学/科学/历史/思想/产业）组织成可检索、可分级、可追溯的索引
- 不做：不复制原文（原文缓存 `.research/literature/`）、不替代 Source Card 流程（`docs/source-notes/`）、不替代作品集正文（`docs/publications/`）

## 分层关系

```text
catalog.md（本层：资料总索引）
  → docs/source-notes/（Source Card / 精读卡片层）
  → .research/literature/（原文缓存层，git 忽略）
  → docs/publications/（作品集正文层：史/指南/手册）
```

## 资料分类体系（与三件套对齐）

| 分类 | 内容 | 对应作品集 |
| --- | --- | --- |
| KB-H 史类 | 神话/古代实践/近代转折/现代技术/思想运动/文学/教训 | 永生史 |
| KB-P 哲学类 | 同一性/意识/死亡/绵延/时间 | 永生指南（哲学判据） |
| KB-S 科学类 | 衰老机制/干预证据/临床方法/流行病学 | 健康手册 + 指南 |
| KB-R 路径类 | 维护/重建/暂停/数字迁移/认知外延/社会复合 | 永生指南 |
| KB-M 思想与产业类 | 超人类主义/长寿运动/产业/伦理治理 | 永生史 + 指南 |

## 索引字段

每条资料条目：

```text
ID | 标题 | 作者/来源 | 年份 | 分类 | 来源分级 | 证据等级 | 对应作品章节 | 状态 | 原文位置
```

- 来源分级：S 史实 / M 神话 / I 思想 / T 技术 / L 教训（史类）；A-D 证据等级（科学类）
- 状态：已入库 / 已卡片化 / 已引用入作品 / 待精读

## 维护规则

- 新增资料：先在 `catalog.md` 登记，再决定是否精读（卡片化）
- 精读卡片进入 `docs/source-notes/`，原文缓存进入 `.research/literature/`
- 作品集引用资料时，引用条目 ID，不复制全文
- 证据纪律：机制≠疗效、动物≠人体、营销≠实证（物理规律约束）

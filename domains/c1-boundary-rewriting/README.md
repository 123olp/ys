# C1 可能性边界改写层

`c1-boundary-rewriting/` 是 `domains/` 下的真实物理分级目录。它收纳所有被 `_possibility-space-control/classification.tsv` 判定为 `C1` 的正式研究域。

## 分级含义

直接改写寿命、死亡、时间、身份连续性和未来抵达边界。

## 维护规则

- 本目录只按可能性空间控制力归类，不按近期可行性、证据成熟度或商业化时间排序。
- 研究域正文仍由各自子目录的 `README.md` 和 `AGENTS.md` 维护。
- 新增、删除或重命名研究域时，必须同步更新 `../_possibility-space-control/classification.tsv` 与 `../_possibility-space-control/summary.md`。

## 当前研究域

- `accelerating-returns-technology-convergence/`：加速回报与多技术收敛，研究 AI、算力、生物技术、纳米技术、脑机接口和自动科研是否压缩技术窗口。
- `biostasis-cryopreservation/`：生物停滞与冷冻保存，研究主体结构保存和未来恢复边界。
- `brain-preservation-connectomics-emulation/`：脑保存、连接组和仿真，研究脑结构、人格连续性和数字化迁移边界。
- `disembodied-cns/`：去具身中枢生命系统，研究主体生命维持与身体承载分离边界。
- `future-waiting/`：未来等待与时间差分路径，研究低固有时成本抵达未来的边界。
- `longevity-evidence/`：长寿证据与长寿逃逸速度，研究延寿干预和寿命边界证据。
- `memory-editing/`：记忆编辑，研究记忆痕迹、人格连续性和身份边界。
- `recursive-self-improvement-intelligence-explosion/`：递归自我改进和智能爆炸，研究 AI 改进 AI 是否压缩技术进步周期。
- `singularity-control-interpretability-boundary/`：奇点控制与解释权边界，研究超人 AI 后的解释、控制、治理和选择权断裂。
- `superhuman-intelligence-threshold/`：超人智能阈值，研究技术系统何时超过人类通用智能并改写未来可达边界。

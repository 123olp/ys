### Human Infra 追问

这个域如何直接改写主体持续性边界，例如寿命、死亡、时间差分、身份连续性或未来抵达能力？

```text
研究域对象
  -> 影响变量 / 中间机制
  -> 改变主体状态或外部条件
  -> 改变风险、能力、时间成本或可达性
  -> 改变有效寿命、有效时间或未来选择权
```

### 使用边界

- 本域是研究与建模单元，不是个体医疗、法律、金融、工程、教育或安全操作建议。
- 新增内容必须标明来源、适用对象、证据等级和不确定性；AI 总结不能作为事实源。
- 若内容会改变分级、目录位置或上下游关系，先更新 `domains/_possibility-space-control/classification.tsv`。

## 研究推进骨架

### 最小问题集

- 界定本域直接改写的主体持续性边界：寿命、死亡、身份连续性、时间差分或未来抵达能力。
- 说明主体连续性条件：身体、记忆、人格、行动能力或法律身份中哪些必须保持。
- 列出不可越过的中止门槛：退出失败、连续性失败、尾部风险、不可逆损伤或治理失效。
- 说明它如何改变有效寿命、有效时间、未来选择权或可能性空间。
- 明确本域不能被宣传成现实永生、工程可行性或个体行动方案。

### 变量接口

- 输入变量：本域直接处理的对象、资源、技术、环境、制度或状态。
- 中间机制：变量通过什么因果路径改变主体状态、系统状态或外部条件。
- 状态改变：身体、认知、能力、资源、风险暴露、可及性、时间成本或协作条件如何变化。
- 风险 / 成本函数：死亡风险、失能风险、工程风险、尾部风险、机会成本、维护成本或治理成本如何变化。
- 输出指标：有效寿命、健康寿命、有效时间、主观时间、相对时间、行动能力、恢复能力或未来选择权。

### 证据入口

- 官方 / 原始资料：监管文件、数据库、临床登记、标准、论文原文、项目白皮书或一手报告。
- 综述 / 指南 / 标准：系统综述、领域指南、技术标准、伦理规范和权威机构材料。
- 数据集 / 登记系统：可复核的数据表、代码、实验记录、登记号、版本和采集边界。
- 反例 / 失败案例：负结果、副作用、安全事故、不可复现结果、伦理争议和误用案例。

### 最小产出

- Source Signals：记录候选资料、来源、日期、主张和待核验点。
- Source Cards：提取 claim、变量、机制、证据类型、边界、反证条件和可迁移位置。
- Claim-Evidence Matrix：把每个稳定主张绑定到来源、证据等级、适用范围和不确定性。
- 变量表：列出输入变量、中间变量、状态变量、风险变量、输出指标和可观测代理指标。
- 上下游关系：说明本域依赖哪些更根本域，并向哪些转化、应用或基础设施域输出。

本子域研究一种远期生命形态：自然身体和器官依赖被外部生命支持、传感器、控制器、执行器和神经接口替代，仅保留生物脑或中枢神经系统作为主体连续性的核心载体。

本域当前采用的主导思路是“接口观察”：不再把心脏、肺、肝脏、肾脏、感官或四肢当作第一研究对象，而是先问这些器官通过哪些通道和大脑交换了什么。血流、氧气、营养、代谢废物、激素、免疫信号、内感受信息、感觉输入与运动指令，才是需要被定义、测量、约束和审查的接口对象。

因此，器官在本域中只是脑-身接口协议的原生实现；真正需要保留的是器官经由接口对脑产生的因果作用。候选替代路线必须先说明交换内容、方向、频率、精度、允许误差和闭环效果，再讨论生物、机械或计算实现。

本域现在采用“接口等价准入”作为第一门槛：若一条路线不能说明脑与身体之间交换了什么、沿哪个方向交换、以什么时间约束和精度交换、误差如何中止以及该通道如何影响主体状态，它只能作为形态类比或来源信号，不能作为身体替代、工程可行或主体持续性收益主张。

## 范式变更

本次思路变更把本域从“器官替代学”推进为“脑-身接口协议学”。心脏、肺、肝脏、肾脏、感官和四肢不再是最终研究对象，而是协议实现；真正的研究对象是它们对脑产生的血流、氧气、营养、清除、激素、免疫、内感受、外感受和运动闭环作用。

本域的研究重心从“能不能复制或替换某个器官”转向“能不能复现该器官对脑和主体连续性的接口因果作用”。

本域采用 `接口观察法`：先把自然身体视为一组实现细节，观察脑与身体之间交换的内容、方向、频率、精度、允许误差和闭环效果；再判断候选生物、机械或计算实现是否能在这些协议边界内产生同等因果作用。

```text
原问题：复制身体结构
  -> 心脏、肺、肝脏、肾脏、感官和四肢能否被完整复制或替换
  -> 容易把器官形态、材料来源或设备外观当作成功判据

新问题：实现接口等价
  -> 脑与身体通过哪些通道交换血流、氧气、营养、代谢废物、激素、免疫信号、内感受、感觉输入和运动指令
  -> 每条通道的内容、方向、频率、精度、允许误差和闭环效果是什么
  -> 哪些生物、机械或计算实现能产生同等输入、接收同等输出并维持同等反馈效果
```

因此，本域的第一判据不是“替代物长得像不像原来的身体”，而是“它是否在脑-身接口协议上产生了足够相同、可观测、可降级、可审计的因果效果”。真正需要保留的不是器官本身，而是器官通过接口对脑产生的维生、感知、调节、表达和行动条件。

更压缩地说，本域的研究对象已经从“身体部件”改为“脑-身接口协议”：

```text
器官 / 肢体 / 身体形态
  -> 只是脑-身交换的原生实现
  -> 不能直接作为主体持续性判据

脑-身接口协议
  -> 定义血流、氧气、营养、废物清除、激素、免疫、内感受、外感受和运动指令如何交换
  -> 记录方向、频率、精度、允许误差、闭环效果和主体状态依赖
  -> 决定候选替代系统是否可能形成接口等价
```

所以本域不问“能否造出同样的身体”，而问“能否在严格边界内实现同样的功能交换，并让同一主体继续处在可感知、可表达、可调节、可行动的闭环中”。

推荐名称：

> 去具身外部维持型中枢生命系统

或更技术化地说：

> 外置生命支持与外部执行器耦合的离体神经中枢系统

## 核心对比

现有人类可以称为“具身半自主开放生命系统”：

```text
生物脑
+ 身体器官
+ 肢体执行系统
+ 感觉系统
+ 自主代谢系统
+ 与外界进行物质 / 能量 / 信息交换
```

目标形态可以称为“去具身外部维持型中枢生命系统”：

```text
生物脑 / 中枢神经系统
+ 人工生命支持系统
+ 电信号输入输出接口
+ 外部控制器
+ 外部执行器
+ 传感器反馈
```

一句话：

> 现有人类是“身体作为主体接口”的生命系统；目标形态是“外部系统作为身体代理”的中枢神经系统。

## 核心理论模块

本域维护“身体功效替代 - 脑身接口协议 - 最小充分身体”作为主理论模块：

- [`docs/body-function-substitution-minimal-sufficient-body.md`](docs/body-function-substitution-minimal-sufficient-body.md)：把软件工程中的接口化、SLO、可观测性、闭环控制、冗余、回滚和安全案例迁移到生命系统重构中，讨论维持主体连续性所需的脑-身交换协议、接口等价和最小身体功效集合。
- [`docs/brain-body-interface-protocol-contract.md`](docs/brain-body-interface-protocol-contract.md)：定义脑-身接口协议的最小字段、状态枚举、示例记录和模型接入规则，用于把叙事转成可审查变量表。
- [`docs/brain-body-interface-protocol-register.json`](docs/brain-body-interface-protocol-register.json)：脑-身接口协议的机器可审计寄存器；当前仅允许 L2/Q2 候选变量，不允许进入临床、工程实施、个体预测或生存收益计算。
- [`docs/minimal-sufficient-body-claim-evidence-matrix.json`](docs/minimal-sufficient-body-claim-evidence-matrix.json)：把最小充分身体、接口等价、局部功效替代、主体连续性边界和治理控制主张绑定到 Source Cards、协议行、变量、反证和降级动作。
- [`literature/README.md`](literature/README.md)：本模块的文献包入口和维护规则。
- [`literature/source-signals.md`](literature/source-signals.md)：候选文献、标准、监管文件和技术资料清单。
- [`literature/source-cards.md`](literature/source-cards.md)：已抽取的 Source Cards，按 claim、变量、机制、边界和反证条件组织。

该模块不把自然身体理解为不可拆分的整体，也不把原生器官形态当作唯一目标；它把身体视为一组通过脑-身接口协议对主体产生因果作用的基础设施集合：

```text
自然身体整体失效
-> 先识别脑与身体之间交换了什么：血流、氧气、营养、代谢废物、激素、免疫信号、内感受、感觉输入和运动指令
-> 为每个交换通道定义内容、方向、频率、精度、允许误差、闭环效果和失败信号
-> 从结构复制转向接口等价，不要求造出同样器官，而要求产生同等输入、接收同等输出并维持同等闭环效果
-> 用生物器官、机械装置、计算控制系统、神经接口和外部执行器分别承接这些交换协议
-> 判断这些接口等价实现是否足以维持同一主体继续存在、感知、行动、学习和选择
```

本域的思路已经从“替换器官”进一步收敛为“保留接口因果作用”：

```text
原生器官形态
-> 通过脑-身接口向中枢产生血流、氧气、营养、清除、激素、免疫、内感受、感觉和运动闭环作用
-> 研究重点不是复制心脏、肺、肝脏或四肢本身
-> 而是识别每条交换通道的内容、方向、频率、精度、允许误差和闭环效果
-> 只要替代系统能产生同等输入、接收同等输出并维持同等反馈效果
-> 就可以讨论接口等价，而不是结构复制
```

## 接口架构

### 自然身体接口架构

```text
环境
↓
氧气 / 水 / 食物 / 感觉信息
↓
身体接口：肺、胃肠、皮肤、感官
↓
内部器官系统：循环、代谢、免疫、内分泌
↓
中枢神经系统
↓
神经-肌肉系统
↓
肢体行动 / 语言 / 表情
↓
环境反馈
```

### 人工接口化中枢架构

```text
环境
↓
传感器 / 供能系统 / 灌注系统 / 维生系统
↓
外部控制器
↓
神经接口
↓
生物脑 / 中枢神经系统
↓
神经输出信号
↓
外部控制器
↓
机械执行器 / 机器人 / 虚拟环境

传感器反馈
↓
神经接口
```

## 研究对象

本子域关注高层系统建模，不提供实验步骤。

核心问题：

- 生命支持系统如何代理自然器官的代谢、供氧、清除、温控和保护功能？
- 神经接口如何建立可解释、可校验、低伤害的输入输出闭环？
- 外部控制器如何避免反馈失真、控制错误和主体表达受损？
- 系统故障时如何降级、恢复和保护主体尊严？
- 如何定义主体连续性、可表达性、可退出性和权利边界？

## 不属于本子域

- 普通长寿干预证据页。
- 医疗建议或手术建议。
- 人体或动物实验操作协议。
- 绕过伦理审查的可执行技术路线。

## 与其他子域的关系

- 与 `longevity-evidence` 的关系：共享证据追溯和风险边界原则，但研究尺度不同。
- 与 `memory-editing` 的关系：共享主体连续性和神经安全问题；本子域关注生命支持与接口，记忆编辑关注记忆痕迹读写。

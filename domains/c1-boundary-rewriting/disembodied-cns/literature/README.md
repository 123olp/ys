# 文献包：身体功效替代与最小充分身体

本目录保存 `disembodied-cns` 域下“身体功效替代与最小充分身体”框架的文献包。

检索日期：2026-07-11。

## 文件

- `source-signals.md`：候选来源清单，记录来源类型、可支持主张和边界。
- `source-cards.md`：按 Human Infra 证据卡格式抽取 claim、变量、机制、证据类型、不能外推内容和下一步动作。
- `papers/README.md`：说明本地 PDF/HTML 镜像的目录、状态和使用边界。
- `papers/manifest.tsv`：记录 `MSB-SIG-001` 到 `MSB-SIG-025` 的本地 PDF、HTML 快照、下载状态和失败原因。
- `papers/pdf/`：保存可通过开放或官方路径下载的 PDF。
- `papers/html/`：保存官方页面、PubMed 页面、PMC 页面或监管页面快照。

## 来源分组

- 中枢基质边界：BrainEx / 离体脑灌注与细胞功能恢复。
- 全身灌注边界：OrganEx / 多器官细胞功能恢复与伦理边界。
- 身体-脑闭环：NIH 内感受计划、内感受与精神健康综述、内感受推断和具身自我。
- 预测控制边界：内感受预测、allostasis 控制和身体状态误差修正。
- 具身认知边界：身体形态、感知运动闭环和环境耦合对主体连续性的约束。
- 局部功效替代：人工胰腺、闭环胰岛素、ECMO/ECLS、人工心脏。
- 神经输入输出：FDA BCI 指南、DARPA NESD、PRIME Study 临床登记、人工触觉输入和神经语音解码。
- 器官替代与模型：组织芯片、异种移植、器官替换监管资料。
- 工程方法迁移：NASA 系统工程、FDA 医疗设备软件验证、STAMP/STPA。

## 阅读透镜

本包所有来源都必须从“接口处”阅读：它们能支持的是某条脑-身交换通道、局部闭环控制、局部生命支持或安全审查方法，而不是完整身体替代。每条来源进入 Source Card 时，都要回答它支持哪类交换内容、方向、频率、精度、误差边界和闭环效果；回答不了的，只能停留在来源信号。

## 使用规则

- 这些来源只支持研究框架、变量建模和证据边界，不证明替代身体、去具身主体或有效永生已经可实现。
- 官方监管材料和论文原文优先；媒体报道只能作入口，不作为强主张来源。
- 涉及生命支持、神经接口、器官替换和人体实验的内容必须保持非操作性。
- `papers/` 是本地来源镜像，不是完整版权论文库；未取得 PDF 的条目必须保留 HTML 快照和 manifest 状态，不能写成“全文已下载”。

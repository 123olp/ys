## MSB-CARD-013：具身认知作为反脑-only 边界

| 字段 | 内容 |
| --- | --- |
| 来源 | Stanford Encyclopedia of Philosophy, `Embodied Cognition`, https://plato.stanford.edu/entries/embodied-cognition/ |
| 类型 | 哲学 / 认知科学综述 |
| Claim | 具身认知传统认为，身体特征可能对认知过程具有重要因果作用，甚至在某些观点中具有构成性作用。 |
| 变量 | 身体结构、感知运动循环、环境耦合、认知任务、身体外部特征 |

| 边界 | 具身认知不是统一理论，也不直接给出替代身体工程规格；它只能作为“不能把主体简化为裸脑”的理论约束。 |
| 反证条件 | 若替代身体完全丢失身体-环境闭环后仍宣称主体不受影响，应判定为理论外推过度。 |

## MSB-CARD-015：内感受预测与脑-身控制接口

| 字段 | 内容 |
| --- | --- |
| 来源 | Barrett & Simmons, 2015, Nature Reviews Neuroscience / PMC, https://pmc.ncbi.nlm.nih.gov/articles/PMC4731102/ |
| 类型 | 理论综述 |
| Claim | 大脑持续预测身体内部状态，并通过预测误差、调节输出和身体反馈形成内感受控制回路。 |
| 变量 | 内感受预测、预测误差、身体内部状态、调节输出、皮层-皮层下环路、allostasis |
| 机制 | 大脑不是被动读取身体，而是主动预测和调节身体状态；身体信号对情绪、行为和状态分配具有反馈作用。 |
| 可迁移位置 | BBIP-002 内感受反馈、BBIP-005 内分泌信号，以及“接口协议不是静态测量表，而是闭环控制协议”的方法论。 |
| 边界 | 该理论不能推出内感受可由少量人工信号完整替代，也不能推出任何替代身体方案已可行。 |
| 反证条件 | 若替代系统只提供血流/氧气等底层维持，却无法解释主体如何获得内部状态预测和误差修正，则不能称为最小充分身体。 |
| 下一步 | 把内感受通道从“身体信号输入”扩展为“预测-误差-调节输出-反馈闭环”。 |

## MSB-CARD-018：神经语音解码与表达输出边界

## MSB-CARD-019：内感受建模与 allostasis 控制语言

| 字段 | 内容 |
| --- | --- |

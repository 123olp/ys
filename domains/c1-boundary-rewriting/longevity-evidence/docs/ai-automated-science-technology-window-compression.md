# AI 自动科研与技术窗口压缩

本文件把“第四次科技革命 / 奇点 / AI 自动科研”类传播材料收束为 Human Infra 中可审查的研究对象：AI 是否正在压缩科学发现、实验验证和技术转化周期，并因此间接改变长寿逃逸速度与主体持续性的外部条件。

本文不把“奇点已经到来”“AI 已经脱离人类控制”“AI 必然带来永生”写成事实结论。它只记录一条可进入模型的机制链：

```text
AI 自动科研 T
  -> 扩大数字假设空间、候选生成速度、自动实验吞吐和反馈闭环变量 X
  -> 改变科学发现、材料筛选、药物研发、蛋白设计和验证系统状态 S
  -> 改变技术窗口出现概率、验证延迟、转化失败率和治理风险 λ(t)
  -> 间接影响长寿逃逸速度、未来医学供给、有效寿命和主体未来选择权
```

## 研究定位

这条路线在 Human Infra 里不是直接延寿干预，而是技术窗口生成与转化通道。

```text
主体持续性最大化
  -> 需要未来医学、材料、能源、计算和自动实验持续产生新解
  -> 新解产生速度受科研基础设施、数据、模型、实验自动化和转化体系约束
  -> AI 自动科研可能压缩发现周期和试错成本
  -> 若压缩能穿过验证、监管、安全和可及性门槛
  -> 则它可能提高主体等待未来技术成熟的概率收益
```

主归属：`C1 / longevity-evidence`，因为它讨论的是长寿逃逸速度能否由 AI 自动科研压缩技术窗口而改写寿命边界。

支撑域：`C3 / ai-drug-discovery-protein-design`、`C4 / research-infrastructure-open-science-translation`。

下游域：细胞重编程、癌症控制、再生医学、免疫维护、材料与设备支持、临床试验监管科学。

## 来源信号与边界

| 信号 | 可采纳主张 | 不能推出 |
| --- | --- | --- |
| AlphaFold, Nature 2021 | 深度学习在蛋白结构预测中达到高精度，改变结构生物学工具链。 | 不能推出蛋白功能、药物疗效或临床治疗已经自动解决。 |
| AlphaFold DB, NAR 2024 | AlphaFold DB 从 2021 年初始规模扩展到超过 214 million 预测结构，并成为开放结构资源。 | 不能写成“2021 年 12 个月内完成 2.14 亿结构”；大规模扩展节点主要在 2022 年后。 |
| AlphaMissense, Science 2023 | 模型可对大规模人类 missense variants 进行致病性倾向预测。 | 不能写成“填满临床致病基因图谱”；预测结果仍需功能实验、遗传证据和临床解释。 |
| GNoME, Nature 2023 | 大规模图网络和主动学习可扩展无机材料候选发现空间。 | 不能把计算稳定材料等同于可合成、可制造、可商业化材料。 |
| A-Lab, Nature 2023 / Correction 2026 | 自动实验室可在闭环中执行材料合成探索；更正后需收缩“新材料”与成功数叙事。 | 不能继续使用“41 种地球上从未存在过的新材料”这类无边界表述。 |
| RoboChem, Science 2024 | 机器人平台可对光催化流动反应做自动优化、强化和放大。 | 不能推出通用新药自动合成或药物研发整体已经超过人类。 |
| Kuhn / Vinge / Kurzweil / de Grey / Cordeiro / Bostrom / Russell | 可作为范式转移、奇点、长寿逃逸速度、AI 风险的思想背景。 | 不能作为实验事实、临床事实或模型输入真相源。 |

## 三层证据结构

### 第一层：自动科研事实层

这一层只允许使用论文、数据库、实验平台报告和更正声明。

可稳定使用的表达：

```text
AI 已经在部分科学任务中显著压缩候选生成、结构预测、材料筛选和实验优化周期。
```

不可稳定使用的表达：

```text
AI 已经接管科研。
AI 已经能自动破解所有科学难题。
AI 已经证明奇点即将到来。
```

### 第二层：技术窗口模型层

这一层把自动科研信号转成 Human Infra 变量。

| 变量 | 含义 | 对主体持续性的可能影响 |
| --- | --- | --- |
| `DiscoveryRate` | 单位时间产生候选结构、分子、材料、机制或实验方案的速度。 | 增加未来技术窗口候选数。 |
| `ValidationLag` | 从计算候选到实验验证、临床前验证、人体试验或工程验证的时间。 | 决定发现速度能否转成真实技术收益。 |
| `ExperimentThroughput` | 自动实验平台单位时间可执行的实验量和反馈速度。 | 压缩试错周期，提高筛选效率。 |
| `EvidenceQuality` | 数据、实验、复现、统计和负结果记录质量。 | 降低错误候选进入下游的风险。 |
| `TranslationProbability` | 候选进入临床、工程、监管或真实部署的概率。 | 决定技术窗口能否变成主体可用路径。 |
| `SafetyAttrition` | 因毒性、不可制造、不可复现、双重用途或伦理风险被淘汰的比例。 | 防止“更多候选”变成“更多噪声”。 |
| `AccessProbability` | 技术成熟后主体实际接触、支付、理解和采用的概率。 | 决定外部技术是否能进入主体系统。 |

最小模型链路：

```text
DiscoveryRate 上升
  -> 候选技术窗口增加
  -> 若 ValidationLag 下降且 EvidenceQuality 不下降
  -> TranslationProbability 上升
  -> 若 SafetyAttrition 和治理风险可控
  -> 可用医学/材料/工具窗口增加
  -> 主体等待未来技术成熟的期望收益上升
```

### 第三层：奇点与长寿逃逸速度推论层

这一层只能作为假设空间，不得作为事实层。

可审查问题：

```text
如果 AI 自动科研持续压缩发现周期，
医学进步速度是否可能超过主体衰老速度？
```

需要同时成立的条件：

```text
候选生成速度提高
  -> 实验验证速度提高
  -> 临床转化速度提高
  -> 安全性和可及性没有同步崩溃
  -> 技术能作用于多类衰老损伤和急性死亡风险
  -> 主体在等待期间仍保持足够连续性和采用能力
```

因此，奇点叙事在 Human Infra 中不是结论，而是一个高不确定性前置条件假设：

```text
AI 自动科研是否能让未来技术窗口的生成速度超过主体风险累积速度？
```

## 对原传播稿的事实修正

| 原传播表达 | 审查后写法 |
| --- | --- |
| AlphaFold 2021 年用 12 个月完成 2.14 亿结构 | AlphaFold 论文发表于 2021 年；AlphaFold DB 在 2022 年扩展到 2 亿以上，NAR 2024 报告超过 214 million 预测结构。 |
| 人工完成需要 7 万年 | 可保留为传播性估算，但不得作为论文级事实，除非绑定明确计算来源。 |
| AlphaMissense 填满人类致病基因图谱 | AlphaMissense 对大规模 missense variants 做预测，帮助解释变异；临床致病性仍需多证据判读。 |
| A-Lab 合成 41 种地球上从未存在过的新材料 | Nature 2026 correction 已收缩“新材料”含义，并确认部分成功数需更正；应写成自动实验室材料合成探索案例。 |
| RoboChem 合成新药速度和纯度超越人类 | RoboChem 论文是光催化流动反应自动优化、强化和放大案例，不应扩大为通用新药自动合成。 |
| 奇点后人类彻底下桌 | 可作为思想实验或风险叙事，不是当前证据支持的科学结论。 |
| 奇点是永生唯一前置条件 | Human Infra 可表达为“强前置变量之一”，但不是唯一条件；医学、制度、资源、风险治理和主体连续性同样必要。 |

## Human Infra 可用论证

推荐写法：

```text
AI 自动科研的价值，不在于它已经证明奇点或永生，
而在于它正在改变未来技术窗口的生成函数。
当蛋白结构、遗传变异、材料候选和化学反应优化被计算化、自动化和闭环化，
主体等待未来医学突破的概率分布可能被改写。
但这个改写必须穿过验证、转化、安全、可及性和治理门槛，
否则发现速度只会变成噪声速度。
```

压缩成一条链：

```text
AI 自动科研
  -> 候选生成和实验反馈速度提高
  -> 未来医学、材料和工具技术窗口增多
  -> 若验证、转化、安全和可及性门槛通过
  -> 主体等待未来升级的期望收益提高
  -> 长寿逃逸速度从纯医学问题变成科研生产函数问题
```

## 禁止外推

- 不把预测结构、预测突变、计算稳定材料或自动优化反应写成“已可治疗人类疾病”。
- 不把单个自动实验室案例写成“全自动科研已经完成”。
- 不把未来学时间表写成证据事实。
- 不输出个体寿命、死亡日期或确定性永生承诺。
- 不把商业新闻稿、媒体标题或视频文案作为一手证据。

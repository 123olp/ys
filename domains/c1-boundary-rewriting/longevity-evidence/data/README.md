# 数据目录

这里存放 Longevity Evidence 子域的公开数据源样例、原始快照和清洗后数据。

## 规则

- `raw/` 用于原始 API 响应或下载文件。
- `processed/` 用于清洗后的结构化数据。
- `manual/` 用于人工整理的首批 MVP 数据。
- `manual/higher_order_effects.tsv` 用于维护 LEV 二阶 / 多阶效应模型输入。
- `manual/lev_route_cards.tsv` 用于维护 LEV 主流路线卡模型输入。
- `manual/life_path_toy_model_scenarios.json` 用于维护生命路径 toy model 的合成队列场景输入。
- `manual/life_path_public_mortality_anchor.json` 用于维护 NCHS 2021 U.S. Life Tables 的公开聚合死亡率锚点，支持 toy baseline plausibility comparison；该文件不包含个人数据，不授权校准预测、干预效果估计或个体死亡日期输出。
- `manual/life_path_nhanes_public_lmf_aggregate_pilot.json` 用于维护 CDC/NCHS NHANES 2017-2018 public-use LMF 的 sex × age band 粗聚合试运行输出；该文件只证明公开真实死亡结局数据能被临时下载、内存连接和聚合导出，不包含行级数据，不授权 survey-population inference、校准预测、因果结论或个体死亡日期输出。
- `manual/life_path_nhanes_public_lmf_survey_design_readiness.json` 用于维护 NHANES public-use LMF 试运行的 survey-design readiness 契约，记录 WTMEC2YR、SDMVPSU、SDMVSTRA 官方字段、Taylor linearization 文档线索和继续阻塞的 estimator/domain/disclosure/calibration gates；它不授权加权人口推断或 design-based confidence interval 输出。
- `manual/life_path_nhanes_public_lmf_domain_subpopulation_rule_readiness.json` 用于维护 NHANES public-use LMF 试运行的 domain/subpopulation rule readiness 契约，记录 CDC/NCHS domain/subpopulation 机制、完整设计输入要求、禁止 row-drop subgroup filtering、eligible base、DOF、disclosure 和 calibration 阻塞门；它不授权 weighted domain inference、design-based confidence interval、校准或个体预测。
- `manual/life_path_nhanes_public_lmf_eligible_base_readiness.json` 用于维护 NHANES public-use LMF 试运行的 positive-weight eligible-base readiness 契约，记录 `WTMEC2YR > 0`、完整设计输入、不预先丢行、5809 名 positive-weight eligible adults、15 个 strata 和 no lonely positive-weight strata；它不授权 weighted domain inference、design-based confidence interval、校准或个体预测。
- `manual/life_path_nhanes_public_lmf_weighted_estimator_readiness.json` 用于维护 NHANES public-use LMF 试运行的 weighted-estimator readiness 契约，记录 R `survey` / `svydesign` 后端选择、`WTMEC2YR`、`SDMVPSU`、`SDMVSTRA`、`nest=true`、design-object、domain indicator 和继续阻塞的 runtime / output / disclosure / calibration gates；它不授权 weighted domain output、design-based confidence interval、校准或个体预测。
- `manual/life_path_nhanes_public_lmf_r_survey_runtime_smoke_readiness.json` 用于维护 NHANES public-use LMF 试运行的 R `survey` runtime smoke readiness 契约，记录 `Rscript`、`survey` 包、synthetic `svydesign`、domain `subset` 和 no-package-install / no-network / no-public-row 边界；它只允许环境探测，不授权 weighted domain output、design-based confidence interval、校准或个体预测。
- `manual/life_path_nhanes_public_lmf_domain_indicator_diagnostic.json` 用于维护 NHANES public-use LMF domain indicator metadata diagnostic 契约，验证 8 个 sex × ageBand 聚合域组合覆盖，同时确认 diagnostic 不重复公开 record counts、death counts、weighted sums、rates、intervals、原始行或个体行；它不授权 weighted domain output、design-based confidence interval、校准或个体预测。
- `manual/life_path_nhanes_public_lmf_dof_sparse_domain_diagnostic.json` 用于维护 NHANES public-use LMF DOF / sparse-domain metadata diagnostic 契约，验证 8 个 sex × ageBand 公开聚合域的 represented DOF、lonely represented strata、empty domain 和 sparse-domain flags，同时确认不持久化行、逐域计数、逐域加权和、rates 或 intervals；它不授权 weighted domain output、design-based confidence interval、校准或个体预测。
- `manual/life_path_nhanes_public_lmf_disclosure_output_envelope_policy.json` 用于维护 NHANES public-use LMF synthetic disclosure output envelope policy，定义 aggregate-only、synthetic-only、small-cell suppression、low-DOF suppression、forbidden keys 和 forbidden output types；它不授权真实 public weighted-domain output。
- `manual/life_path_nhanes_public_lmf_disclosure_output_envelope_test_cases.json` 用于维护 NHANES public-use LMF disclosure envelope 合成 allow/block 测试集，验证 safe synthetic aggregate 输出可通过，row-level、identifier、public AI、small-cell、low-DOF 和 real-output 形状会被阻断。
- `manual/life_path_nhanes_public_lmf_weighted_output_implementation_preflight_policy.json` 用于维护 NHANES public-use LMF synthetic weighted-output implementation preflight policy，定义未来实现必须满足的 R `survey` / `svydesign` / `survey::subset`、no row-drop-before-design、no row persistence、no real weighted output 和 no individual-use 边界。
- `manual/life_path_nhanes_public_lmf_weighted_output_implementation_preflight_test_cases.json` 用于维护 NHANES public-use LMF weighted-output implementation preflight 合成 allow/block 测试集，验证 safe synthetic estimator-plan 形状可通过，row-level、row-drop-before-design、real weighted rate、public AI、count key 和 individual-output 形状会被阻断。
- `manual/life_path_nhanes_public_lmf_disclosure_review_template.json` 用于维护 NHANES public-use LMF 真实公开输出前的 disclosure review 模板，固定 output hash、suppression review、effective sample / CI review、forbidden-field scan、second-reviewer 和 release decision 槽位；它不完成真实 disclosure review，也不授权真实 public weighted-domain output。

- `manual/life_path_nhanes_public_lmf_weighted_domain_output_readiness.json` 用于维护 NHANES public-use LMF weighted-domain output 前的安全门契约，绑定 controlled R `survey` smoke、post-design domain indicator、DOF/sparse-domain metadata diagnostic、synthetic disclosure output envelope、synthetic publication criteria、synthetic implementation preflight、disclosure review template、disclosure review execution register、local-only ignored weighted run 和 real disclosure/output implementation review；它只登记输出前置条件，不授权 public weighted domain rates、design-based intervals、校准或个体预测，并显式要求默认 readiness 审计独立于 ignored local run / packet outputs。

# SBI/OI Claim-Evidence Matrix

Status: `draft-source-bounded-not-reviewed-artifact`

This matrix constrains claims about synthetic biological intelligence, organoid intelligence, living neural computation, scale effects, and "superhuman" narratives. It is a research-domain control document, not an experimental protocol, product evaluation, consciousness assessment, or model-admission artifact.

## Scope

```text
living neural substrate
  -> read/write interface
  -> closed-loop software environment
  -> structured feedback and task ecology
  -> measurable adaptation, information processing, or functional assay behavior
  -> scale-effect hypotheses
  -> Human Infra external cognitive infrastructure analysis
```

## Core Claims

| Claim ID | Claim | Evidence status | Supported interpretation | Forbidden extrapolation | Next evidence needed |
| --- | --- | --- | --- | --- | --- |
| `SBI-CLM-001` | In vitro neural cultures can show task-related adaptation under real-time closed-loop feedback. | `bounded-supported` | Closed-loop feedback can alter measurable task performance in simplified environments. | This is not proof of consciousness, general intelligence, or moral patienthood. | Independent replication across labs, cell sources, task families, and platforms. |
| `SBI-CLM-002` | Structured sensory input can shift embodied in vitro neural networks toward near-critical dynamics. | `bounded-supported` | Critical dynamics may be a useful state variable for information-processing analysis. | Near-criticality alone does not prove learning, agency, or intelligence. | Multi-metric criticality validation and feedback/no-feedback separation across tasks. |
| `SBI-CLM-003` | Closed-loop gameplay metrics can act as functional readouts beyond spontaneous firing alone. | `early-supported` | Drug perturbation can change both neural activity and task performance in an SBI assay. | A gameplay response is not a validated clinical endpoint or therapeutic prediction. | Disease-model validation, dose-response robustness, blinded replication, and clinical correlation. |
| `SBI-CLM-004` | Organoid intelligence requires scale, 3D maturation, richer interfaces, algorithms, data infrastructure, and embedded ethics. | `roadmap-supported` | OI is a multidisciplinary program, not a single result. | Current organoids should not be described as human-equivalent minds or complete cognitive agents. | Durable 3D organoid systems with standardized I/O, task benchmarks, and ethical review triggers. |
| `SBI-CLM-005` | Biological neural networks may have local advantages in sample efficiency, energy use, or online adaptation. | `hypothesis-with-early-task-evidence` | The advantage should be tested per task, metric, and full system cost. | Do not claim universal superiority over silicon AI or human cognition. | End-to-end energy accounting, life-support cost, task transfer tests, and long-run stability data. |
| `SBI-CLM-006` | CL API / CL1-style middleware can reduce the barrier to reproducible closed-loop biological neural experiments. | `platform-claim-with-preprint-support` | API contracts, synchronization, and task environments can become a platform layer. | Product availability does not prove scientific maturity, network effects, or safety. | External adoption data, reproducibility studies, open benchmarks, failure reports, and governance logs. |
| `SBI-CLM-007` | SBI/OI may develop network effects when wetware units, task libraries, feedback protocols, data standards, and research communities accumulate. | `theoretical-synthesis` | Network effects are plausible at substrate, platform, and ecosystem layers. | More neurons, more units, or more users do not automatically mean more intelligence. | Longitudinal platform data showing reusable performance improvements across tasks and labs. |
| `SBI-CLM-008` | SBI/OI could exceed current methods in narrow dimensions before any general intelligence claim becomes meaningful. | `bounded-forecast` | Possible advantage dimensions: low-sample adaptation, energy efficiency, neural functional assays, specific control tasks, disease modeling. | Do not write "will surpass humans" without domain, metric, and evidence. | Dimension-specific benchmarks against humans, AI systems, and conventional assays. |
| `SBI-CLM-009` | SBI/OI is relevant to Human Infra as external cognitive infrastructure, not as a current subject-transfer path. | `framework-supported` | It may expand the possible tool substrate for learning, modeling, and decision support. | It does not support mind upload, digital resurrection, or personality continuity claims. | Transfer-boundary cards linking SBI/OI outputs to actual subject-continuity variables. |

## Scale-Effect Stack

| Layer | Positive mechanism to test | Key variables | Failure modes | Admission rule |
| --- | --- | --- | --- | --- |
| Neural substrate scale | Larger or richer neural tissue may expand state space and adaptive dynamics. | `N_cells`, 3D structure, glia, myelination, maturity, E/I balance, viability window | Necrosis, noise, seizure-like instability, batch effects, unreadable dynamics | Requires task improvement beyond activity complexity. |
| Interface scale | Higher-resolution read/write may improve task coupling and reproducibility. | Electrode density, I/O bandwidth, latency, synchronization, stimulation semantics | Interface bottleneck, tissue damage, non-comparable stimulation, hidden scheduling artifacts | Requires explicit timing and synchronization evidence. |
| Closed-loop environment scale | More tasks and feedback protocols may expose transferable learning. | Task library, feedback quality, reward/error semantics, benchmark ladder | Overfitting to toy games, ambiguous reward, non-replicable behavior | Requires cross-task transfer or at least multi-task robustness. |
| Platform scale | APIs, logs, datasets, and cloud orchestration may create reusable wetware workflows. | API contract, metadata, data standard, run logs, lifecycle tracking | Vendor lock-in, opaque failures, unreviewed claims, reproducibility gap | Requires external users and auditable run records. |
| Ecosystem scale | More labs and use cases may increase replication and discovery speed. | Independent labs, publications, negative results, ethics reviews, open benchmarks | Hype loop, publication bias, ethics lag, commercial overclaiming | Requires independent fresh review and public failure accounting. |
| Governance scale | Stronger complexity and moral-risk gates may prevent unsafe extrapolation. | Consent, donor rights, moral-status triggers, stopping rules, public language | Moral uncertainty grows faster than oversight; public narrative collapses terms | Requires embedded ethics and downgrade rules before scale-up claims. |

## Downgrade Rules

- If evidence comes from one task family, write `task-bound`, not `general`.
- If evidence comes from vendor materials, write `vendor-claimed`, not `independently established`.
- If a result uses preprint evidence, write `preprint`, not `stable consensus`.
- If a system adapts under feedback, write `closed-loop adaptation`, not `consciousness`.
- If a metric improves under drug treatment, write `functional assay signal`, not `clinical efficacy`.
- If scale increases but task transfer is absent, write `larger substrate`, not `higher intelligence`.
- If moral-status uncertainty increases with complexity, freeze capability claims until ethics and stopping rules are explicit.

# 公开仓库不得承载私有产品源码

## 阻止条件

- Git 已跟踪 Wiki、科技树或永生年表的源码、结构化产品数据、发布脚本、运行时数据或构建物。
- 以文档整理、备份、候选参考或部署便利为由重新创建产品源码副本。
- 公开仓库的 CI、Makefile、结构检查或治理上下文重新取得三产品构建所有权。
- 门禁失败信息回显私有仓库路径、文件内容或凭据。

## 原因

公开研究文本与产品源码具有不同的访问、发布和变更风险。产品源码必须只有一个私有真相源；公开仓库只保留研究摘要、引用和稳定公开入口。

## 检查方式

- 本地：`make public-product-boundary`。
- CI：在依赖安装前执行 `python3 tools/audit_public_product_boundary.py`。
- Review：确认新增路径和脚本没有重建 Wiki、Tree 或 Timeline 的产品所有权。

## 可操作错误提示

公开产品边界门禁阻止了变更。请把产品源码迁回私有产品仓库，并只在本仓库保留公开摘要或稳定 URL。错误输出只能包含规则、数量和 `location_id`。

## 最小修复

- 删除公开工作树中的产品源码副本。
- 在私有产品仓库完成构建、测试和部署。
- 将公开引用改为产品稳定 URL，不得链接私有仓库地址。

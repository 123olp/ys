# GATE-0003 历史年表事件必须完成来源与审阅连续性

## 阻止条件

- 事件从 `draft` 直接进入 `published`，未经过 `locally_reviewed` 和 `fresh_reviewed`。
- 公共《永生史》正文引用了 `unreviewed`、`blocked` 或 `needs_revision` 的事件。
- 事件缺少来源、证据等级、不确定性或生命周期状态。
- 来源不可访问时仍保持 `published` 或 `fresh_reviewed`。
- 来源之间存在日期或解释冲突，但未保留多来源解释，也未标记 `blocked` / `needs_revision`。
- 神话、文学或远期设想被写成已验证史实。

## 原因

- 永生史属于跨文明、跨时期的严肃历史工程，来源与审阅连续性决定其能否作为公共作品的可信底稿。
- 把“待考证”误升为“已证明”，会把历史教训变成伪证据。

## 检查方式

- manual: 按 `docs/reference/history-timeline/GOVERNANCE.md` 审阅事件生命周期。
- manual: 检查 `verification_status`、`status`、`sources`、`evidence_grade`、`uncertainty` 是否完整。
- semi-automated: 用 `tools/validate_history_timeline.py` 检查必需字段和状态枚举，但独立审阅不能由机器替代。

## 可操作错误提示

- `review=FAIL reason=unreviewed_published` 表示未复核事件进入发布。
- `review=FAIL reason=source_unreachable` 表示来源失效但状态未降级。
- `review=FAIL reason=evidence_overclaim` 表示把神话、文学或远期设想写成已证明事实。

## 最小修复

- [ ] 将事件状态降回 `draft` 或 `needs_revision`。
- [ ] 补齐来源、证据等级、不确定性和复核记录。
- [ ] 来源失效时置为 `blocked` 或 `needs_revision`。
- [ ] 完成本地复核和独立审阅后再升入 `published`。
- [ ] 更新公共《永生史》正文，移除未复核引用。

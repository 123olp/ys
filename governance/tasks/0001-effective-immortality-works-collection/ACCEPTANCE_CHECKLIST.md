# Acceptance Checklist

# Global Standards

1. 三件套时间维度定位正确：史=过去、手册=现在、指南=未来（含重叠区）
2. 每项内容基于真实机制与可验证事实，明确标注确定性与风险（物理规律约束）
3. 健康手册每条方法挂证据等级，区分"实证/候选"，风险与停止条件不省略
4. 永生指南每条路径标证据等级 + 阻塞点，不写成玄幻清单
5. 永生史事件按来源分级（史实/神话/思想/失败教训），不混入虚构
6. 编排层定位：引用研究域而非复制内容
7. 内部使用：不因治理规则稀释关键信息

# Task-Level Acceptance

## TP-01 永生史（过去）

- 覆盖六类事件：神话宗教、古代实践、近代转折、现代技术事件、思想运动与文学影响、失败教训
- 每事件含：时间、人物/文明、内容、来源分级、对有效永生的意义
- 与永生指南的路径族可交叉引用

## TP-02 健康手册（现在）

- 覆盖维度：营养膳食、补剂、身体活动、睡眠、代谢与筛查、环境与社会
- 每方法含：方法、机制、证据等级、剂量/频率（如有实证）、监测指标、风险与停止条件
- 补剂区分"有实证"与"证据不足"两区

## TP-03 永生指南（未来）

- 覆盖路径族：生物维护、生物重建、生物暂停、数字迁移、认知外延、社会复合、哲学判据
- 每条路径含：机制、当前证据等级、阻塞点、时间窗口估计、与健康手册的衔接
- 哲学判据（体验-记忆-选择连续性）作为判定"哪条路算数"的标尺

## TP-04 骨架与索引

- 三件套目录结构落盘
- 相互引用约定（史→指南、指南↔手册重叠区）
- 与项目现有资产（研究域/证据制度）的衔接说明

# Validation Plan

- 校验方式：内容自审 + 交叉引用一致性检查
- 校验项：
  1. 时间维度定位正确（史/手册/指南）
  2. 每项内容标注确定性与风险
  3. 健康手册每条方法挂证据等级
  4. 指南每条路径标阻塞点
  5. 史事件按来源分级
- 通过标准：上述五项全部满足

# Review Gate

- 未到 REVIEW 阶段
- REVIEW 时自审清单：证据标注、路径阻塞点、事件来源分级、交叉引用一致性

# Runtime Verification Gate

- 无代码/运行逻辑变更；验证以内容自审与交叉引用一致性为主
- 若用户反馈内容错误或证据误标，按 bugfix 处理并补 RED/GREEN 证据

# Ship Readiness

- 未就绪：待 BUILD/TEST/REVIEW 完成
- 就绪标准：三件套内容完成、交叉引用一致、证据标注齐全、内部可用

# Task Package Acceptance

- TP-04 骨架与索引先行验收：目录结构、交叉引用、项目资产衔接
- 三件套各自完成后，整体验收时间维度定位与交叉引用一致性

# Anti-Goals

- 不得虚构历史事件、证据等级或路径可行性
- 不得把"候选/推测"写成"实证"
- 不得复制研究域内容替代引用（编排层定位）
- 不得在未确认 A1-A4 前直接进入全量内容编写

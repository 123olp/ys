# Task Overview
- Task ID: `0001`
- Slug: `effective-immortality-works-collection`
- Objective: `搭建公共作品集三件套：永生史（过去）、健康手册（现在）、永生指南（未来），服务于有效永生目标`
- Status: `EXECUTION`

## In Scope

搭建三个相互衔接的公共作品集，形成一条完整认知链路：

```text
过去 ←────── 永生史（人类已经走过的全部路）
现在 ←────── 健康手册（此刻就能执行、实证支撑的方法）
未来 ←────── 永生指南（所有可能的路径：现在可走 + 未来可能）
```

| 作品集 | 时间维度 | 对象 | 形态 |
| --- | --- | --- | --- |
| 永生史 | 过去 | 神话宗教、古代实践、近代转折、现代技术、思想运动、文学影响、失败教训 | 时间线/事件史 |
| 健康手册 | 现在 | 实证支撑的可执行健康维持方法：营养、补剂、运动、睡眠、代谢、筛查、环境 | 执行手册 |
| 永生指南 | 未来 | 所有可能路径：生物维护、生物重建、生物暂停、数字迁移、认知外延、社会复合、哲学判据 | 路径地图 |

核心原则：
- 目的：**有效永生**；作品集是认知手段
- 用途：内部使用，个人决策辅助
- 唯一约束：物理规律；内容基于真实机制与可验证事实，标注确定性与风险
- 第一原理锚点：主体的"体验-记忆-选择"三重连续性必须被无限保持

## Out of Scope

- 不新建研究域、不修改 `domains/` 结构与证据制度本身
- 不公开发布（内部使用）
- 不涉及与三个作品集无关的仓库整理、重构、重命名
- 不做实验操作、医疗方案承诺或个体处方输出（物理规律红线仍保留风险标注）

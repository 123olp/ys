# Assumptions and Falsification

- 假设 1：三件套时间维度切分（过去/现在/未来）成立。反证：若用户认为健康手册属于指南的一部分，则调整结构。
- 假设 2：内部使用不需要公开审查强度。反证：若未来转公开，需补传播边界。
- 假设 3：物理规律约束下，"证据纪律"仍是理性的必要组成。反证：若用户明确要求包含无证据内容，须显式标注"推测"。

# Critical Ambiguities

- A1：健康手册粒度——决策型（方法+证据+怎么选）还是操作型（含执行细节/排期/追踪表）
- A2：永生指南组织方式——按路径族（机制）还是按时间窗口（现在可走/10-30 年/远期）
- A3：起步形态——骨架版（结构+核心内容+待补项）还是完整版
- A4：作品集物理落点——`docs/publications/` 新目录 vs docs 既有层级

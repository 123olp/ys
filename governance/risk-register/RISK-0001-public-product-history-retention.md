# 公开 Git 历史仍保留已迁移产品资产

## 风险

Wiki、永生年表与科技树参考资产已从公开仓库当前分支移除，但普通删除不会移除历史提交中的对象。知道旧提交或对象标识的人仍可能读取历史内容，外部克隆、缓存和分叉也无法由本仓库控制。

该风险当前属于产品源码与知识资产暴露，不等同于已确认凭据泄露；凭据与本机身份由完整历史隐私门禁单独审计。

## 当前控制

- 当前分支由 `GATE-0005` 和 `make public-product-boundary` 阻止产品源码回流。
- 三产品后续维护只在私有产品源码控制面进行。
- 完整 Git 历史继续执行脱敏凭据与隐私扫描。

## 剩余处置

若确认旧历史必须从 GitHub 可达对象中移除，需要单独批准并执行历史重写、镜像备份、强制推送、协作者重新克隆和发布引用修复。该操作不能撤回外部副本，因此不得被描述为“完全消除既往公开”。

## 关闭条件

- 已完成并验证历史重写，且所有受控远端不再可达目标对象；或
- 所有者书面接受历史公开不可逆性，并把相关资产正式降级为可公开历史资料。

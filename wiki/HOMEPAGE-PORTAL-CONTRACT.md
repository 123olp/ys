# Human Infra 首页与专题门户契约

## 页面层级

| 层级 | 职责 | 禁止事项 |
| --- | --- | --- |
| 语言门户 | 选择语言、搜索路由、版本状态 | 研究结论、词条正文、虚假语言版本 |
| 项目首页 | 策展当前语言的重要入口与动态 | 复制完整专题、硬编码易漂移统计 |
| 专题 Portal | 定义范围、组织路径、连接相关对象 | 代替证据页、产生独立疗效结论 |
| 专题综述 | 综合特定问题的机制、证据和边界 | 越过引用支持范围 |
| 研究对象页 | 保存研究域、技术节点、证据来源的真相 | 与首页或 Portal 形成并行正文 |

## 中文项目首页

`Human Infra:首页` 是中文版本首页。页面结构固定复用中文维基百科首页 `mp-2012` DOM 与 `TemplateStyles` 样式机制；官方 Wikitext、页首、CSS 和渲染 HTML 必须作为不可手改的固定快照保存，页面由生成器从快照构建。`Template:首页/*` 只承载 Human Infra 内容，不得创建平行布局系统。首页至少包含：

1. 项目定义、动态词条统计和主要导航。
2. 特色研究与终极目标入口。
3. 专题 Portal。
4. 证据动态及其支持边界。
5. 争议、未知与反证入口。
6. 标准录入、内容方针和版权入口。
7. 历史谱系、科幻思想实验和代码仓库入口。

首页上游来源、固定修订、许可证和允许适配范围记录在 `homepage-upstream/UPSTREAM.md`。`Human_Infra_Main_Page.wiki`、`Template_Home_Header.wiki` 和 `Template_Home_styles_css.wiki` 是生成产物，任何直接编辑都属于契约违规。更新上游前必须比较 DOM 契约、桌面/移动布局和深浅色模式，不得仅凭截图手写仿制。

`MediaWiki:Mainpage` 是首页路由真相源；`首页` 只保留兼容重定向。

## Portal 页面

`Portal:` 命名空间用于跨对象导航。每个 Portal 必须包含：

- 明确的研究范围和非声明。
- 概览和对应专题综述。
- 精选研究、核心研究域和关键技术节点。
- 证据入口、支持边界和不可外推范围。
- 开放问题、争议、风险、失败条件或禁止推论。
- 参与建设入口和相关 Portal 导航。

Portal 中出现的强主张必须链接到承担该主张的研究对象或证据页。Portal 只做导航和压缩表达，不能成为孤立证据来源。

Portal 使用 Vector 与 MediaWiki 原生标题、列表、表格和链接，不在正文重复页面一级标题，不新增 `hi-portal` 一类平行布局 CSS。需要更复杂的通用组件时，应先评估 MediaWiki 官方模板、TemplateStyles 或受治理的模板导入，而不是在 `MediaWiki:Common.css` 手写门户框架。

## 分类层级

`Category:Human Infra Wiki` 是唯一顶级分类。专题、专题门户、研究域、技术节点、证据来源、科幻作品参照、模板和隐藏维护分类都必须通过有限父链追溯到该分类。

- `Category:模板` 组织模板维护分类。
- `Category:信息框模板` 和 `Category:首页模板` 是隐藏的模板子分类。
- 模板页自身的维护分类必须放在 `<noinclude>` 中，禁止把调用模板的普通词条误归入模板分类。
- 分类页和 Portal 一样依赖 MediaWiki 原生页面标题，正文不得重复一级标题。

## 更新责任

- 新增顶级专题时同时评估首页入口、Portal、专题综述和分类。
- 首页统计使用 MediaWiki 魔术字或 API，不手工维护。
- 删除或重命名词条时检查首页模板和所有 Portal 的入链。
- 每次导入后通过 smoke test 验证首页路由、Portal 命名空间和关键页面。
- 每次提交前运行 `make homepage-check`；快照哈希、唯一槽位锚点或生成结果任一漂移均必须阻塞。
- 首页运行时、MediaWiki 或 Vector 版本发生变化后，使用 BackstopJS Docker 在同一浏览器环境中执行官方参考图与本地页面的逐像素比较；尺寸或像素任一不一致都必须进入差异报告，禁止用 DOM 抽样、提高容差或忽略文本渲染替代视觉回归。
- 官方实时首页包含动态栏目、中央通知和持续变化的正文；视觉门禁只能采用明确记录时间和来源的冻结参考图。更新参考图必须人工审查，禁止把本地测试图批准为官方标准。
- 模板契约比较必须在官方页和本地页中注入同一标准内容夹具，并按页首、左右栏区块、链接区和项目区分别截图，使零像素差异只评价模板、样式和响应式结构；未经标准化的整页比较只用于发现内容量、品牌与运行时差异，不得冒充模板 Gate。
- 官方标准化组件参考图必须进入版本控制；只允许从官方 `referenceUrl` 重新生成，不得使用 `approve` 将本地失败截图晋升为标准。
